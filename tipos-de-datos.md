# Tipos de datos

### ¿Cuáles son algunos tipos de datos JS?

En JavaScript, hay varios tipos de datos que se utilizan para almacenar información.

### 1. Números

Este tipo de datos se utiliza para representar tanto números enteros como decimales.

**Ejemplo:**

> ```javascript
> let edad = 25; // Número entero
> let temperatura = 36.6; // Número decimal
> ```

#### 2. Cadenas de texto (String)

Las cadenas de texto son secuencias de caracteres y se pueden definir usando combinaciones simples, dobles.

**Ejemplo:**

> ```javascript
> let nombre = "Juan"; // Usando comillas dobles
> let saludo = 'Hola, ¿cómo estás?'; // Usando comillas simples
> ```

#### 3. Booleanos (Booleano)

Este tipo de dato solo puede tener dos valores: `true(verdadero) o false(falso)`. Se utiliza en condiciones cómodas y bucles.

**Ejemplo:**

> ```javascript
> let esEstudiante = true;
> let tieneLicencia = false;
> ```

#### 4. Objetos

Los objetos son colecciones de propiedades y pueden contener múltiples valores en forma de pares clave-valor.

**Ejemplo:**

> ```javascript
> let persona = {
>     nombre: "Ana",
>     edad: 30,
>     esEstudiante: false
> };
> ```

#### 5. Nulo (Nulo)

El valor `null`se utiliza para indicar que una variable no tiene ningún valor o que está vacía.

**Ejemplo:**

> ```javascript
> let coche = null; // No hay un coche asignado
> ```

#### 6. Indefinido (Indefinido)

Una variable que ha sido declarada pero no se le ha asignado un valor tiene el valor

indefinido.

**Ejemplo:**

> ```javascript
> let mascota; // No se ha asignado un valor
> console.log(mascota); // Imprime "undefined"
> ```
